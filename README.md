# 🏨 Hotel Feedback Form

A fully structured, accessible, and semantic web form built with HTML5 to collect guest feedback, ratings, and preferences for a hotel stay.

---

## 🚀 Features & Components

* **Semantic Field Groups:** Organized into logical sections using `<fieldset>` and `<legend>` tags.
* **Rating & Selection Controls:** 
  * **Dropdown Menus:** Built using `<select>` and `<option>` elements to rate services.
  * **Radio Buttons:** Custom single-choice inputs (`type="radio"`) for exclusive selection.
  * **Checkboxes:** Multi-option selections (`type="checkbox"`) for amenities and preferences.
* **Text Inputs & Validation:** 
  * Text fields with `<label>`, `placeholder`, `required`, and format validation.
  * Multiline text area (`<textarea>`) for detailed guest reviews.
* **Form Action & Submission:** Standard `<form>` setup prepared for server-side processing with submit buttons.

---

## 🛠️ Technologies Used

* **HTML5:** Pure semantic markup, web forms, and client-side validation attributes.
